About

PortsFallout, maintained by dbaio, provides an easy way to search/query the FreeBSD pkg-fallout archive.

The same data is available from a read-only API. The filters of these pages work there too, under the same names, so every fallout of a maintainer is either the start of an address or the whole of one:

$ curl -s 'https://portsfallout.com/api/fallout/?format=json&maintainer=ports'
$ curl -s 'https://portsfallout.com/api/fallout/?format=json&maintainer=ports@FreeBSD.org'

Any of them takes a regular expression as well, here and there: ?maintainer=^(ports|x11)@. The API section of the README covers the rest: pagination and what search matches.

A date bounds the answer, which is how a copy is kept current without walking the whole archive again:

$ curl -s 'https://portsfallout.com/api/fallout/?format=json&date_after=2026-09-01'
